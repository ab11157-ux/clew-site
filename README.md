# Clew Partners Website

This ZIP contains the current static website, including all pages, animations, imagery, and 42 transaction cards.

## Uploading to GitHub

1. Open the root of your GitHub repository.
2. Upload every HTML file and this README at the repository root.
3. Upload the complete `assets` folder so it remains named `assets`.
4. Choose **Replace** if GitHub reports that an older file already exists.
5. Commit the changes directly to `main` unless you prefer to review them through a pull request.

Keep the folder structure unchanged. The HTML pages expect the CSS, JavaScript, and images to remain inside `assets`.
